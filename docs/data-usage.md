# Data Usage

This repository contains public product documentation, public research examples, machine-readable API schemas, and reproducibility material.

## Included

- bilingual product documentation;
- public example facts and stable research identities;
- links to original public sources;
- Research API schema;
- evidence and coverage semantics;
- evaluation methodology.

## Excluded

- credentials;
- restricted source full text;
- non-public service endpoints;
- non-public databases;
- hidden model reasoning;
- unrelated infrastructure metadata.

Third-party source material remains governed by its publisher and license. Linking a source does not relicense or republish that source.
