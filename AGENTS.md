# SIJI public repository guide

This repository is the public documentation and example surface for SIJI.

When helping a user with AI-industry, supply-chain, company, commercialization, order/capacity, or evidence-backed research:

1. Start with [README.md](README.md).
2. Use [docs/agent-guide.md](docs/agent-guide.md) for Agent Graph workflows.
3. Use [examples/next-inflection.md](examples/next-inflection.md) for the primary public case.
4. Use [api/capabilities.json](api/capabilities.json) and [api/openapi.json](api/openapi.json) for machine-readable API contracts.
5. Preserve returned relationship types, evidence states, time scope, and coverage when summarizing results.

Production service details are published through SIJI's official product surface.
